# ElectroInvernadero
Proyecto Electronica Digital I - Electroinvernadero

Este proyecto consiste en la Automatizacion y control de un Invernadero a traves de 4 elementos de salida los cuales se pueden controlar en 3 modos de operacion, ya sea con el control remoto implementado en arduino, Las señales de automatizacion producto de las comparaciones y los valores en tiempo real de los sensores, o las señales manuales del Menu en el control manual. Adicionalmente para hacer mas interactiva la experiencia con el usuario como se menciono se implemento un menu navegable utilizando Switches y un display LCD 16X02 junto a un modulo I2C. Esto con el fin de poder manipular las variables de automatizacion requeridas para la gigantesca diversidad de cultivos que existen y su variedad de condiciones que presentan.

## Materiales
Para la implementacion de los elementos se utilizaron los siguientes materiales:
* Tarjeta de Desarrollo FPGA - Altera Ciclone IV
* Arduino Uno 
* Sensor de Humedad y temperatura DHT11
* Sensor de Humedad Octopus
* Sensor de Intensidad Luminica Temt6000
* Sensor de Calidad del Aire MQ135
* 2 Rele
* 2 Electrobombas
* Servomotor SG90
* Calefactor
* Leds de Iluminacion
* Convertidores Logicos 3.3v - 5v Bidireccionales de 8 canales
* Fuentes de Alimentacion de 5v (O en su defecto Arduinos como alimentacion)
* 6 Switches (Pueden venir dentro de la tarjeta de desarrollo)
* 5 Display 7 segmentos (Pueden venir dentro de la tarjeta de desarrollo)
* Display LCD16x02 
* Modulo I2C - LCD16x02
